博物馆导览 支持

联系方式

如需帮助、报告问题或提出建议，请在 GitHub 上提交 issue（需要一个免费的 GitHub 账户）。请注明你使用的设备，以及出问题的博物馆和作品。请不要在那里填写个人信息或付款信息。

常见问题

如何收听作品讲解？

打开作品页面，点按“收听”。讲解播放时，文字会随之高亮。点按任意小节标题旁的播放按钮即可从该处开始，点按“停止”即可结束。

没有网络时能用吗？

可以。出发前在“设置”的“离线下载”中下载该博物馆的录音和大图。如果没有下载，“收听”会在线播放录音；离线时则使用设备自带的语音朗读。

能同时看中文和英文吗？

可以。在“设置”中打开“中英对照”，作品页面会逐段显示两种语言，讲解则使用你选择的语言。

相机找不到我面前的作品

让作品尽量占满画面，避开强烈反光，并保持片刻不动。你也可以从屏幕底部的推荐中直接选择作品。未开通高级版时，每天可以通过相机打开三件作品。

高级版包含什么？

无限次通过相机打开作品、通过 iCloud 在所有设备间同步收藏夹和笔记，以及无广告。可按月或按年订阅。

如何恢复或取消高级版？

在新设备上恢复：在 App 中打开高级版页面，点按“恢复订阅”，并使用订阅时的同一个 Apple 账户。取消订阅：打开设备的“设置”，点按你的名字，再点按“订阅”。取消后不会再自动续订，高级版会一直可用到已付费周期结束。

收藏夹没有同步

请确认 App“设置”中的“iCloud 同步”已打开，并且每台设备都用同一个 Apple 账户登录了 iCloud。更改可能需要一分钟左右才会出现在其他设备上。

如何更改广告选项？

在“设置”中点按“广告隐私选项”。
